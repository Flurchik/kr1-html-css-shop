# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — страница карточки товара;
- `order.html` — страница оформления заявки;
- `contacts.html` — контактная информация и FAQ;
- `css/style.css` — файл стилей;
- `js/main.js` — файл JavaScript;
- `images/` — папка для изображений;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Использование Flexbox и Grid
В проекте используются:
- Flexbox для основного меню;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров.

## Использование позиционирования
В проекте продемонстрировано применение ключевых свойств позиционирования (раздел 10 методических указаний):
- `position: relative` — карточки товаров `product-card` как опорный контейнер;
- `position: absolute` — бейджи `product-card__badge` («Хит», «Скидка», «Новинка») внутри карточек;
- `position: sticky` — верхняя шапка `site-header` и боковой блок фильтров `catalog-filters`;
- `position: fixed` — фиксированная кнопка быстрого перехода «Наверх» `scroll-top`;
- `z-index` — управление наложением слоёв модального окна, шапки и кнопки «Наверх».

## БЭМ-структура проекта
В проекте используются следующие БЭМ-блоки и модификаторы:
- `site-header` — шапка сайта (`site-header--sticky`);
- `site-nav` — основная навигация (`site-nav__link--active`);
- `breadcrumbs` — хлебные крошки (`breadcrumbs__link--active`);
- `hero` — первый экран главной страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара:
  - `.product-card--featured` — флагманский товар (выделенная рамка и градиент);
  - `.product-card--discount` — товар со специальной скидкой;
  - `.product-card--new` — новинка каталога;
  - `.product-card__badge--discount`, `.product-card__badge--new` — позиционированные ярлыки;
- `product-detail` — разметка детальной карточки товара (Minecraft Dungeons);
- `product-table` — семантическая таблица характеристик товара (`caption`, `thead`, `tbody`, `th`, `td`);
- `reviews`, `review-card` — блок и карточки отзывов покупателей с рейтингом и датой;
- `catalog-layout` — двухколоночная структура страницы каталога;
- `catalog-filters` — боковой фильтр каталога (`position: sticky`);
- `order-layout`, `order-summary` — структура страницы заказа со сводкой корзины;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `faq` — блок часто задаваемых вопросов на тегах `<details>` и `<summary>`;
- `scroll-top` — фиксированная кнопка возврата «Наверх»;
- `button` — кнопка (`.button--primary`, `.button--secondary`);
- `site-footer` — подвал сайта.

### Основные доработки (делал сам, советуясь с ИИ)
1. **Кнопка «Наверх»**: фиксированная кнопка (`position: fixed`) с плавной прокруткой.
2. **Блок FAQ**: интерактивный аккордеон на `contacts.html` на тегах `<details>` и `<summary>`.
3. **Sticky-фильтр каталога**: боковой фильтр (`position: sticky; top: 140px;`) и 6 товаров в каталоге.
4. **Работа с изображениями**: обложки с `aspect-ratio: 16 / 9` и `object-fit: cover`.
5. **Блок отзывов**: секция `reviews` на `product.html` с Grid-сеткой карточек `review-card`.
6. **БЭМ-модификаторы карточек**: `.product-card--featured`, `.product-card--discount`, `.product-card--new`.
7. **Состояния кнопок и карточек**: эффекты `:hover`, `:active`, `:focus-visible`, `:focus-within`, `:disabled`.
8. **Доступность форм (A11y)**: атрибуты `aria-required`, `aria-describedby`, `autocomplete`.

### Дополнительные улучшения (сделаны с помощью ИИ для визуального оформления и удобства)
1. **Тёмная тема**: геймерская палитра (`#0f1017`, `#181b29`, фиолетовый акцент `#8b5cf6`).
2. **Таблица характеристик**: семантическая таблица `product-table` (`caption`, `thead`, `tbody`, `th`, `td`).
3. **Продвинутое модальное окно**: анимация, размытие фона, закрытие по клику вне окна/Esc, автоподстановка выбранной игры.
4. **Калькулятор заказа (`order.html`)**: динамический пересчёт стоимости при смене игры на JS.
